安装本仓库的三个技能，再按 README 准备官方飞书 CLI 与技能。

按仓库地址安装：

```sh
npx skills add LadyK666/feishu-writing-workflow -a codex
```

公开仓库可供下载，但不等于所有 Codex 自动发现。搜索入口可参考 [Skills CLI](https://github.com/vercel-labs/skills) 和 [skills.sh](https://www.skills.sh/docs/faq)；产品目录分发参见 [OpenAI 插件文档](https://developers.openai.com/plugins/build/plugins)。收录情况以实际结果为准。
