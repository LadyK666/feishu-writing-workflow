# 飞书文档编辑案例

以下均为虚构的请求与验收条件，不含远程文档地址，不表示已经在线执行。

| 场景 | 输入与权限 | 应有结果 | 不应发生 |
|---|---|---|---|
| 实验记录成报告 | 现有结论与数据；允许重组，不允许新推断 | 结论、证据表与范围说明相互对应 | 新增倍率、原因或统计显著性 |
| 长文精简 | 方案有收益，也有尚未验证的条件 | 删重复与旁支，保留影响判断的限制 | 把“部分条件下可用”改成“可用” |
| 只美化 | 原文、数据、顺序不变；指定章受保护 | 字重与整格底纹改善阅读，保护区完全保留 | 新增标题、箭头或总结，重建保护章节 |
| 逐指标表 | 同组可比数据，含精确并列 | 独立标 mean、median、p95 与并列最优 | 整行指标任意加粗或完全不标 |
| 文字表 | 事项与“尚未确认负责人” | 强调“尚未确认”，保留否定含义 | 擅自补负责人或只强调“确认” |
| 局部翻译 | 只改一节，保留引用和图 | 目标节翻译，其他块与资源不变 | 全篇重排、引用丢失 |
| 无可用连接 | 仅能处理本地输入 | 交本地稿，说明未写入飞书 | 给出虚构的在线完成状态 |
| 写入状态不明 | 调用中断，可能已追加 | 先回读核对，再决定重试 | 直接再追加，形成重复内容 |

这些案例用于检查通用边界，实际任务仍按读者、来源与用户授权决定表达方式。它们不是声称已完成的行为测试记录。
