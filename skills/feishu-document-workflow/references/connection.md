# 引用现有飞书连接技能

连接、授权与具体命令交给上游技能，本文件只说明写作工作流如何接入，不重复维护账号配置或 CLI 手册。

## 使用哪一个技能

| 任务 | 引用的上游技能 |
|---|---|
| 首次配置、认证、身份、scope 或授权故障 | [lark-shared](https://github.com/larksuite/cli/tree/main/skills/lark-shared) |
| 文档读取、新建、导入、编辑与资源 | [lark-doc](https://github.com/larksuite/cli/tree/main/skills/lark-doc) |
| 搜索、真正复制文档、文件权限、独立评论 | [lark-drive](https://github.com/larksuite/cli/tree/main/skills/lark-drive)，按任务安装 |

这些技能与官方 CLI 从 [larksuite/cli](https://github.com/larksuite/cli) 获取，安装方法见项目 README。使用前读取已经安装的相应技能及当前场景参考；具体参数以上游和当前工具帮助为准。

## 复用本地适配层

环境已有 `feishu-bridge-docs` 或其他连接适配层时，可以复用其有效工具入口和登录态；不要求新用户拥有同名私有技能。此类适配层不在本包中，也没有由本包提供的下载地址。

适配层中的账号、应用配置、授权缓存和绝对路径属于使用者环境，不写入公共技能或读者正文，不传给子模型。普通文档读写不要求另行运行聊天机器人桥接服务。

## 工作流边界

主进程持有连接，执行飞书读取、认证、写入和回读。子模型只接收最小必要的本地材料与当前语法说明，返回草稿、来源和疑点。

代表用户本人编辑文档时，按上游选择用户身份；不把机器人资源当作用户资源。已有可用授权不重复配置或登录，只有实际身份、权限或认证错误才按上游修复。

Sheet 与 Base 走对应官方能力，不套用 Docx 文档表格操作。写入结果不明时先回读，避免重复插入；无法连接时交付本地稿并明确尚未写入飞书。
