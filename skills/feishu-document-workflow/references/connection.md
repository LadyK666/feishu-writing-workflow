# 飞书连接与工具选择

本包提供写作方法，不提供凭据、账号配置或私有连接脚本。连接只由主进程持有。优先复用已有且适用于任务的连接，避免为了套用本包更换用户工具或重置配置。

## 推荐的官方工具

参考 [larksuite/cli](https://github.com/larksuite/cli) 安装当前版本及其 `lark-doc`、`lark-shared` 技能。需要搜索、真正复制文档、权限或独立评论操作时，按任务使用官方 `lark-drive`。不在本包中复制这些上游文件，避免陈旧命令与许可混淆。

首次连接按官方当前步骤配置和用户授权。不要默认创建新应用、切换账号、扩大权限或反复重新登录。遇到未认证、身份或权限错误时，再按 `lark-shared` 当前指引修复；用户完成扫码等动作后才能继续依赖该授权的操作。

文档代表用户本人创建或编辑时，使用用户身份；不把机器人自身的资源空间误当成用户账号。官方文档操作推荐显式 `--as user`；具体参数先读取当前参考或帮助，不能猜测。

## 路径与版本

普通写作无需每次跑整套环境预检。工具找不到、入口不一致或版本行为异常时，先诊断：

```powershell
Get-Command lark-cli -All
lark-cli --help
lark-cli docs --help
```

上述为 Windows PowerShell 的诊断示例；其他环境使用自身的命令查找方式。确认当前实际入口、版本与 PATH；只在本地修复，不把某个人的绝对路径写成公共技能默认值，也不把私有包装器当作所有用户都安装的依赖。

输入文件、输出文件和富文本语法以当前工具参考为准；优先使用工作目录内的相对路径和文件输入，避免大段内联内容造成转义问题。不同官方版本或参考存在差异时，先核对实际帮助，不将本地补丁泛化成官方接口。

## 场景路由

| 场景 | 处理 |
|---|---|
| 读取或摘要文档 | 先读官方读取参考，获取正文、结构及任务所需资源 |
| 从资料新写文档 | 按官方创建工作流生成可写入草稿，再创建并验证 |
| 空白文档或原样导入 | 按官方空文档/导入入口，不伪造额外创作步骤 |
| 已有文档编辑或美化 | 按官方更新参考，使用稳定目标定位和最小修改 |
| 真正复制文档 | 走平台复制能力；重新创建正文不等于完整副本 |
| Sheet 或 Base 数据 | 转交其对应官方能力，不能套用 Docx 文档表格操作 |

这张表是任务路由，非固定 CLI 命令清单；具体语法由当前官方技能负责。

## 失败与隐私

错误信息只保留必要诊断字段，不输出令牌、密钥、完整授权配置或原始认证日志。凭据不发给子模型，不进入文档正文、示例或开源包。

写入结果不明确时先回读目标状态，再决定是否重试，防止重复插入。无法连接时保留本地成品并报告未写入；不能把连接失败改写成已完成。
