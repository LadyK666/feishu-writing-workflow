# 飞书文档写作工作流

以飞书文档为交付载体，先确定允许改变什么，再组织资料、正文和表格，由主进程审核、写入和回读。本技能用于文档写作与编辑，不把 Sheet、Base 内部数据或云盘权限管理当作普通文档表格操作。

## 确定本次任务

从请求和已有语境确定资料来源、目标文档或创建位置、读者目的、允许修改的内容/结构/样式/数据，以及保护范围。缺少关键信息时再提问，已确认的授权和偏好不重复询问。

| 类型 | 编辑边界 |
|---|---|
| 新写 | 根据已提供资料组织章节与表格；未知保留未知 |
| 改写、翻译 | 在指定范围调整表达，保留事实、术语、条件和引用 |
| 精简、提取 | 按读者问题取舍细节，保留会改变理解的证据与限制 |
| 结构调整 | 按授权移动或合并内容，核对引用、资源和标题关系 |
| 仅格式 | 保留字句、数据、显示精度、顺序和结构，只改样式 |
| 表格内容或结构编辑 | 只执行明确要求的增删、字段调整或数据更新 |
| 计算、分析 | 仅在授权范围计算，保留方法与来源，不伪装为原文结果 |
| 审阅、本地稿 | 输出问题或草稿，不写回线上 |

“不新增计算或推断”不禁止在清楚口径内比较现有指标值以选择粗体，但禁止生成新倍率、收益、统计显著性或因果结论。

## 飞书操作归主进程

读取 [连接说明](references/connection.md) 复用现有连接技能。文档操作引用官方 [lark-doc](https://github.com/larksuite/cli/tree/main/skills/lark-doc)，配置与认证引用 [lark-shared](https://github.com/larksuite/cli/tree/main/skills/lark-shared)；读取它们已安装的当前参考，不在本技能重写命令与授权手册。这些上游能力需要另行安装，不包含在本包中。已有本地连接适配层可以复用，不把其私有配置变成公共依赖。

主进程统一执行飞书读取、配置与认证、资源获取、创建、修改和回读。子模型只处理指定本地材料，不访问飞书、不运行 CLI、不读取凭据、不请求扫码、不直接写回。

空白文档、原样导入、微小编辑直接处理。确有收益的复杂任务按 [子任务交接](references/delegation.md) 拆分资料、章节、表格或审阅，不强制固定角色或层层转派。

## 组织文稿与表格

读 [资料与表达](references/writing.md) 中相关部分。先区分来源事实、原有结论、建议与未知，再按读者任务组织内容。过程用步骤，连续解释用段落，精确字段对照用表格，提醒条件用简短提示；不强制每节放表或彩色提示块。

表格设计使用同包 [table-writing-and-styling](../table-writing-and-styling/SKILL.md)。它负责指标方向、同组逐指标最优值、语义重点、整格底纹与默认蓝绿配色。不能把文字高亮当作单元格填充，也不能把方法身份或汇总身份当成指标最优。

写作、精简和表旁说明只使用本次授权的证据。仅格式且逐字不增减时，不加入箭头、总结或新的表注。

## 审核、写回、交付

按 [写回与验收](references/publishing.md) 检查成品与来源、权限边界及保护范围。主进程审查子模型真实交付物，合并去重并统一术语，再执行最小必要写入。

保存与修改范围有关的内容、结构和资源基线。写前检查目标与版本；遇到冲突先重读，不盲目覆盖。写后回读文字、数据与样式，能访问页面时检查实际排版。

交付实际文档链接或本地草稿，说明已完成检查和未验证部分。不能把草稿生成、CLI 退出成功或 XML 文本一致分别等同于已经写入、最终版面正常或全部评论资源完好。内部工作流与模型分工默认不进入面向读者的正文。
