# 按表格类型组织

## 论文、实验与消融

围绕一个比较问题安排方法、条件与指标。表头包含必要单位和有定义的方向；表注解释缩写、样本、误差项和比较口径。消融表让读者能看出改变了什么因素，不将同时改变多个因素的结果归因为其中一个。

论文三线表通常采用少量横线，避免满格边框和大面积彩色填充，遵从模板。汇报表可以对同样的数据使用浅色分组。不要把适合报告的彩色表格强加给期刊版式。

统计表保留效应量、区间或标准误、样本量与统计符号。不要机械把系数或 p 值的最小值认作“最好”。

## 语义文字表

选择围绕读者问题的列，例如“问题—依据—决定”或“事项—状态—下一步”。已有表只美化时不重排、不删列。

加粗能帮助读者做决定的原有短语：结论、行动、依赖、异常和限制。少量文字强调形成层次，避免整格粗体。否定词和条件属于重点的一部分，例如强调“尚未验证”，不能只强调“验证”。

日期、编号与句子里的数字不自动作为指标。状态颜色需有一致含义，且文字本身能表达状态，不能只靠红绿区分。未知责任人保留为未知，不补人名。

## 文献与能力矩阵

清楚定义维度，区分已验证、未提供与不适用。每条判断保留可追溯依据。不能把“资料未提及”填成“不支持”，也不为凑齐表格编造引用。

## 计划、业务与汇总

让事项、时间、依赖、状态、金额或指标口径容易查找。已授权的汇总可以单列；纯样式编辑不新增合计、排序或公式。汇总行可用底纹表达身份，不把其中数字当作性能获胜值加粗。

## 混合表

按列或内容片段处理：指标部分使用分组最优规则，结论部分使用语义强调，身份和分类使用底纹。不要因存在一列数值而禁止全表文字强调，也不要把文字表的重点规则扩展成任意数字加粗。
