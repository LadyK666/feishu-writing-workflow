# 飞书表格的执行与验证

本技能返回表格内容、分组、指标方向和样式位置。[feishu-document-workflow](../../feishu-document-workflow/SKILL.md) 审核成品，[feishu-bridge-docs](../../feishu-bridge-docs/SKILL.md) 按官方能力完成原生表格写入与回读。

## 原生样式

整格或整行底纹用单元格背景，数值与文字重点用富文本片段字重；保留块、合并关系、链接与资源。工具不支持某种样式时说明限制，不用文字色块冒充整格底纹，也不用截图替代可编辑表格。

本地 Markdown 只表达草稿与基本字重，不证明最终飞书版面。Sheet 和 Base 数据由连接层转交对应官方能力。

## 验证

1. 按授权范围核对文字、数字显示、顺序、单位、公式、链接、合并关系与保护区。
2. 检查同组逐指标最优标记，预期集合与实际集合相等；总结有来源，条件和否定不丢失。
3. 回读单元格背景、富文本片段、对齐和宽度；在实际页面检查折行、截断与对比度。

评论、锚点和嵌入资源按实际编辑方式单独检查；未验证的部分明确报告。被分派的子模型只交本地成品、来源和设计说明，不访问飞书。
