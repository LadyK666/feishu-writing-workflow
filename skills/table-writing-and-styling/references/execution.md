# 执行、交接与验证

## 按目标平台实现

本技能没有自带连接器、登录脚本或渲染器。使用环境已有工具完成原生表格编辑；平台不同，不承诺某种源码能直接通用。

| 载体 | 实现重点 |
|---|---|
| 飞书等在线文档 | 使用文档原生单元格背景与富文本片段字重；保留块、链接、资源和保护区域，写后回读 |
| Word | 使用原生单元格底纹、段落与文本片段样式；渲染检查跨页表头、行高和数字换行 |
| LaTeX | 遵循模板，以 booktabs 等已有工具表达层次；保留标签、引用与表注，编译检查溢出 |
| HTML | 使用语义化表头与表题，按单元格设置背景；检查窄屏与实际浏览器渲染 |
| 电子表格 | 保留公式、类型和数字格式；使用单元格样式，核查条件格式范围 |
| Markdown | 支持基本表与粗体，通常不支持可移植的整格底纹；不要承诺颜色会在所有查看器呈现 |

## 可选子任务

小任务直接完成。只有确有益处时拆成来源整理、文字精简、表格设计或审阅，不固定角色数量。

子模型接收最小必要的本地材料、用户权限边界和目标产物；返回完整草稿、来源对应、保留与修改清单、比较分组、预期强调位置及疑点。它不连接远程账号、不请求验证码、不接收凭据、不直接修改线上内容。

主进程负责读取授权来源、审核子任务产物、执行远程写入和回读。发现越权内容或数据差异时，修正草稿后再写入。部分写入失败时先读取实际状态，避免盲目重试造成重复插入。

## 分层验收

1. 内容：按任务范围核对文字、数字显示、行列顺序、单位、公式、链接、合并关系及保护区。
2. 证据：指标方向、比较范围、并列与缺失处理正确；实际最优标记集合与预期集合一致。总结能追溯到来源。
3. 样式：回读整格底纹、字重片段、对齐和宽度；不以请求发送成功替代检查。
4. 视觉：在实际阅读尺寸检查折行、截断、层次和对比度；未渲染时明确说明。

涉及评论、修订、锚点和嵌入资源时，文本一致不足以证明它们被保留。根据实际编辑方式单独检查，能力不足则报告未验证部分。
