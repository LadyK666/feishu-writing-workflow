# 默认蓝绿配色与布局

默认方案适用于屏幕阅读的文档与汇报；用户配色、品牌规范、论文模板和灰度打印优先。

| 用途 | 建议色值 | 用法 |
|---|---|---|
| 正文 | `#172B4D` | 深色正文和指标；浅底上保持清晰 |
| 表头 | `#E8F0FC` | 完整表头单元格，配深色字与结构字重 |
| 主要分组 | `#F2F6FD` | 一组连续行或分组标签的浅蓝底纹 |
| 辅助分组 | `#EAF7F3` | 确有第二层分组或辅助信息时使用 |
| 强调文字 | `#146A64` | 少量语义重点或辅助标签，不替代粗体最优值 |
| 边线 | `#D8E2ED` | 克制的分隔，避免厚重满格线 |

没有分组时不为使用两种颜色而制造分组。浅色底纹表达区域与身份；指标最好值仍以深色粗体标记。不要把整行绿色解释为所有指标获胜。

底纹应铺满完整单元格或整行。文字高亮和段落背景不会自然覆盖整格，不能用一格格的文字色块冒充单元格底色。平台不支持整格底纹时，优先用字重、间距与边线，并说明限制。

文字多的列给足宽度并允许折行，数值列保留完整数值。表头与内容对齐一致；多层表头的跨度必须准确。大表可冻结表头或重复表头，但是否可用取决于目标载体。

在实际尺寸下检查文字与背景对比度，避免仅用颜色传达结论。针对需要无障碍交付的载体，检查普通文字至少 4.5:1 的对比度要求；灰度检查中分组和重点仍应可辨。来源：[WCAG 对比度说明](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)。
