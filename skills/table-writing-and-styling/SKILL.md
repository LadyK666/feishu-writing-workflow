# Table Writing & Styling

负责飞书文档中的表格设计与美化。[feishu-document-workflow](../feishu-document-workflow/SKILL.md) 提供资料与编辑范围，审核本技能返回的表格；[feishu-bridge-docs](../feishu-bridge-docs/SKILL.md) 将设计应用到飞书并回读。独立表格设计可以直接使用本技能。

## 先确定修改权限

| 请求 | 默认允许 | 保留的边界 |
|---|---|---|
| 从资料成表 | 设计字段、归纳来源、组织行列 | 不编造数据、引用或结论 |
| 编辑指定内容 | 修改指定字段或结构 | 不顺带改其他数据与结论 |
| 只美化、只改格式 | 字重、整格底色、对齐、宽度、间距 | 原文、数字显示、顺序与结构不变 |
| 写作或精简 | 在授权范围重组文字、取舍细节 | 保留影响解释的条件、限制与来源 |
| 审查建议 | 指出问题并给出方案 | 没有写回授权时不改源文档 |

格式编辑保留 `0.50` 与 `0.5` 的区别、原始缺失标记、单位、脚注、链接、公式、合并关系和受保护区域。比较用的数值与原始显示字符串分开保存。只美化不默认新增派生计算。

方向箭头、表注和总结会增加文字。任务允许阅读标注时才插入；明确逐字不增减时，建议放在交付说明中。不要因为不能加字而取消可正确执行的样式调整。

## 按内容选择规则

从来源与上下文识别：读者的问题、表格类型、比较范围、目标载体。只有缺失信息会改变含义或关键比较时才提问；可先完成不依赖答案的部分。

- 论文、实验、消融、统计、文字、计划或混合表：读 [表格类型](references/table-types.md) 中相关部分。
- 有指标或密集数据：读 [指标与大表](references/metrics.md)。
- 涉及底纹、颜色或布局：读 [配色](references/colors.md)。
- 写入平台、子任务交接或验收：读 [执行与验证](references/execution.md)。

## 设计顺序

1. 根据读者要回答的问题安排结构。新表可调整组织方式；只改格式时显现已有分组，保留行列与合并结构。
2. 文字通常左对齐，数字通常右对齐。列宽取决于内容；完整数值不应折成难以读取的碎片。保留单位与必要表注。
3. 区分指标值和语义文字。指标粗体表示定义范围内的最优值；文字粗体突出原有判断、行动与限制。混合表按列或片段处理。
4. 默认用浅蓝与浅青绿形成层次，正文保持深色。底纹铺满完整单元格或整行，不用文字背景块代替整格底色。已有模板、品牌或打印约束优先。
5. 仅在授权且有来源支持时补简短表旁说明，交代比较动机、主要结果或解释边界。不要为了好看添加结论。

## 指标粗体的含义

同一子集、同一条件、同一指标和统计口径内比较。方向明确时使用 ↑ 越高越好、↓ 越低越好；方向未知、目标区间或描述字段不机械加箭头。

mean、median、p95 各自判断。精确并列同等加粗；缺失与无效值不作为零。一个单元格含多个统计量时，只加粗各自获胜的数值片段，分隔符与覆盖数保持普通字重。

不能因为某行是汇总、基线或作者方案就把指标值整行加粗。分组身份可以用浅底纹表达。选择现有数值中的最优值是样式决策，不产生新指标；也不能据此声称显著、因果或普遍领先。

## 交付条件

已有表先保存内容与结构快照，再做最小修改。远程服务由主进程操作；可选子模型只处理提供的本地材料并返回草稿与样式说明，不授权、不登录、不直接写回。

回读后检查内容、数字显示、顺序、资源与保护范围。指标表同时检查是否误标和漏标最优值；并列也必须覆盖。实际阅读尺寸下检查表头折行、数值完整性、对比度和强调密度。

分别报告内容检查、样式回读与视觉检查。工具不支持某种样式时说明限制，给出可编辑的降级方案；不把源码验证称为实际版面验证。
